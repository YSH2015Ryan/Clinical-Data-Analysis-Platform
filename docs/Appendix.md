## C. AI Coding Agent 执行规范与代码生成约束

后续 Coding Agent 实现本项目时**必须遵守**：

1. **蓝图即契约**：实现以本目录文档为准；与蓝图冲突时先提变更（更新文档）再改代码，禁止静默偏离。
2. **不重新实现已有成熟算法**：指标、模型、预处理一律调用 03 章技术栈清单中的库；新增依赖需在 PR 说明理由并通过许可证检查。
3. **分层纪律**：`engines/*` 禁止 import fastapi/celery/ORM Session；CI import-linter 强制（12 章 §1）。
4. **契约同源**：API 改动必须先改 14 章 OpenAPI 节选与 Pydantic schema，前端类型只从生成物获取，禁止手写接口类型。
5. **测试先行**：每个引擎模块先写失败测试（19 章对应条目）再实现；提交必须附带对应单测。
6. **幂等与隔离**：所有 worker 任务幂等（唯一约束兜底）；单模型失败不得影响其他模型。
7. **安全红线**：禁止 eval/exec 用户输入；SQL 全部参数化；密钥不进仓库；上传走白名单+magic 嗅探。
8. **结果真实**：报告与推荐理由只引用真实计算指标，禁止生成未计算的数值或医学断言。
9. **提交规范**：Conventional Commits；PR 关联 18 章 Task 编号（如 `T5.3`）。
10. **完成定义**：以各 Task 的 DoD + 验收标准为准，而非「代码能跑」。

## D. 术语表

| 术语 | 含义 |
|---|---|
| C-index | 一致性指数，生存模型排序能力指标（0.5=随机，1=完美） |
| IBS | Integrated Brier Score，生存预测概率误差 |
| DCA | 决策曲线分析，评估不同阈值下净获益 |
| KM | Kaplan-Meier 生存曲线 |
| CoxPH | Cox 比例风险模型 |
| RSF | 随机生存森林 |
| Table 1 | 临床论文基线特征表 |
| Nomogram | 列线图，临床风险评分可视化 |
| chord | Celery 原语：并行任务组 + 全部完成后的回调 |
| Quick Fix | 校验报告触发的在线数据修复（产生新版本） |
| 金标准回归 | 固定数据+配置比对指标基线，防依赖升级漂移 |
