## 🔍 失败用例分析

### 失败1: 数据校验规则 - 异常值检测

**用例**: `test_data_validation_rules`

**失败代码**:
```python
z_scores = np.abs((data['col3'] - data['col3'].mean()) / data['col3'].std())
outliers = (z_scores > 3).sum()
assert outliers > 0  # 期望检测到异常值
```

**原因**: 
- 测试数据 `[1, 2, 3, 4, 1000]` 中，由于 1000 的极端值影响了均值和标准差计算
- Z-score 标准化后，1000 的 z-score 约为 2.23，未超过阈值 3
- 这是 Z-score 方法的固有限制（对极端值不够敏感）

**影响**: 不影响核心功能，实际应用中可使用 IQR 方法检测异常值

**建议**: 
```python
# 改用 IQR 方法
Q1 = data['col3'].quantile(0.25)
Q3 = data['col3'].quantile(0.75)
IQR = Q3 - Q1
outliers = ((data['col3'] < (Q1 - 1.5 * IQR)) | 
            (data['col3'] > (Q3 + 1.5 * IQR))).sum()
```
