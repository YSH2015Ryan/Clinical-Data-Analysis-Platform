## ⚠️ 已知限制

### 1. Ollama 本地服务

**状态**: ⚠️ 未启动

**影响**: LLM 服务自动降级到云端模式

**原因**: Ollama 需要单独安装和配置

**解决方案**:
```bash
# 安装 Ollama (可选)
curl -fsSL https://ollama.ai/install.sh | sh

# 启动 Ollama 服务
ollama serve

# 下载 Qwen2.5 模型
ollama pull qwen2.5:7b
```

**优先级**: 低（云端备选方案可用）

---

### 2. 端口暴露

**状态**: ⚠️ 部分端口未直接暴露

**当前配置**:
- API: 内部端口 8000（通过 Caddy 反代）
- 前端: 内部端口 80（通过 Caddy 反代）
- Caddy: 暴露端口 80/443

**影响**: 无法直接访问 http://localhost:8000

**解决方案**: 通过 Caddy 反向代理访问（生产环境推荐配置）

**优先级**: 低（符合生产实践）

---

### 3. 镜像构建

**状态**: ⚠️ 新代码未纳入镜像

**当前方式**: 手动复制文件到运行中的容器

**影响**: 容器重启后文件丢失

**解决方案**:
```bash
# 重新构建镜像
cd deploy
docker-compose build

# 重启服务
docker-compose up -d
```

**优先级**: 高（生产部署前必须执行）
