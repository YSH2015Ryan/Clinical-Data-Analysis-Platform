# 用户使用手册（T8.5；面向医生与科研人员）

> 平台地址：`http://服务器IP:8080`（以部署手册为准）。本手册按真实操作顺序编写，跟着点即可完成一次完整分析。
> **免责声明**：本平台输出仅供科研参考，不构成临床诊断或治疗建议；报告中附同样声明。

## 1. 登录与角色

打开平台地址，输入管理员发给你的邮箱和密码登录。

| 角色 | 能做什么 |
|---|---|
| viewer（查看者） | 查看项目、数据集、分析结果与报告 |
| researcher（研究者） | viewer 全部 + 建项目、传数据、跑分析、出报告 |
| admin（管理员） | researcher 全部 + 管理模型插件、创建账号 |

忘记密码 / 需要新账号：联系管理员（部署手册第 5/10 节）。

## 2. 第一步：创建项目

1. 登录后进入「项目」列表页，点 **新建项目**。
2. 填项目名称（如「2 型糖尿病预后研究」）与描述，保存。
3. 点项目名进入项目详情页 —— 之后的所有数据与分析都挂在该项目下。

> 数据按项目隔离：你只能看到自己名下的项目（管理员除外）。

## 3. 第二步：上传数据并校验

1. 项目详情页点 **上传数据集**，选择 CSV / Excel 文件（`.csv .xlsx .xls .tsv .txt`，单文件 ≤200MB）。
2. 上传后平台自动执行**数据校验**（几秒到几十秒），进入数据集详情页可看到：
   - **校验结果**：通过 / 有警告 / 有阻塞；
   - **问题清单**：每条问题标明严重度（阻塞=必须先处理，警告=建议处理）、所在列与说明；
   - **列画像**：每列的类型、缺失率、异常值个数、取值范围等。
3. 处理问题的三种方式：
   - **一键修复**：问题清单里带修复按钮的项（如去重、缺失值处理），点击后生成**新版本**，原文件不动；
   - **语义角色纠正**：列画像中若某列被误判类型（如把「是否吸烟」0/1 当成连续变量），在下拉框改语义角色；
   - 修改源文件后重新上传。
4. 校验「通过」或仅剩警告后，数据集状态变为 **VALIDATED**，才能用于分析。

> **上传前请务必完成脱敏**：删除姓名、身份证号、手机号、病历号等直接标识列。

## 4. （可选）预处理与版本

数据集详情页的预处理面板支持以「步骤」方式追加处理：缩放、编码、分箱、缺失值填补、衍生列（表达式求值，已做安全沙箱）等。每一步可配置参数，保存后生成新版本；**版本列表**中可查看每次处理记录与回滚对比，原始版本始终保留。

> 不确定怎么配？可以先不配 —— 分析向导会根据数据画像**自动推荐**预处理方案，直接使用即可。

## 5. 第三步：新建分析（向导，5 步 ≤6 次点击）

项目详情页点 **新建分析**（或数据集详情页点 **开始分析**），进入分析向导：

1. **选择数据集**：下拉选择已 VALIDATED 的数据集（从数据集页进来会自动选中）。
2. **预处理**：平台自动给出推荐配置，确认或微调。
3. **任务识别**：平台自动识别任务类型（分类 / 回归 / 生存分析）并给出置信度与理由；识别不准时可手动改选。
4. **选择模型**：列出该任务类型的全部可用模型，默认全选，按需勾选。
5. **确认提交**：核对摘要，点提交。

提交后自动跳转到**运行监控页**。

## 6. 第四步：查看运行与模型比较

**运行监控页**实时刷新每个模型的进度（排队 / 运行中 / 成功 / 失败）与耗时：

- 单个模型失败**不影响**其他模型；失败模型可点 **重跑**；
- 可 **取消** 整个运行；
- 运行完成后点 **查看比较** 进入比较页。

**模型比较页**：

- **指标对比表**：各模型的主指标（AUC / R² / C-index 等）、次要指标、耗时；失败模型附错误原因；
- **排名与推荐理由**：按「主指标 60% + 稳定性 20% + 次要指标 20%」加权排名，推荐结论**只引用真实计算出的指标**；
- **图表**：指标雷达图 / 柱状图，特征重要性或 SHAP 摘要（树模型）。

## 7. 第五步：生成报告

比较页点 **生成报告**（或进入报告页）：

| 格式 | 用途 |
|---|---|
| **PDF** | 打印/归档，含完整图表 |
| **HTML** | 浏览器内交互预览 |
| **Word (docx)** | 可二次编辑，章节与 HTML 同源 |
| **Markdown** | 纯文本存档（图表以占位标注） |

生成约需几秒到 1 分钟，状态变为 READY 后可**在线预览**或**下载**。报告包含：数据概况、预处理记录、任务与模型配置、各模型指标、比较与推荐、特征重要性、**免责声明**。

## 8. 管理员：插件管理

管理员在「项目」页可见 **插件管理** 入口：

- **启用/禁用**模型：禁用后新建分析时不再可选（历史运行结果不受影响）；
- **默认参数**：JSON 形式编辑某模型的默认超参数（如 `{"C": 2.0}`），保存后对后续运行生效。

## 9. 常见问题（FAQ）

| 问题 | 解答 |
|---|---|
| 支持什么数据格式？ | CSV / TSV / TXT（逗号或制表符分隔）、Excel（.xlsx/.xls）。编码自动识别（UTF-8/GBK 等）。 |
| 一次分析要多久？ | 与数据量和模型数有关。10 万行 × 50 列 × 6 个模型约 6–7 分钟（实测见 docs/perf-report.md）；单模型 15 分钟超时自动失败。 |
| 数据会传到哪里？ | 平台部署在**院内服务器**，数据不出院；传输与存储均在内网。 |
| 能删数据吗？ | 项目/数据集可删除；删除操作会写入审计日志。 |
| 生存分析需要什么列？ | 时间列（如随访月数）+ 事件列（0/1，如是否复发），任务识别时会提示。 |
| 报告里的推荐可以直接用于临床吗？ | **不可以**。平台输出仅供科研参考，任何临床决策须由具备资质的医师做出。 |
